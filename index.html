01Why LiquidBox

不是毛玻璃，
是真的液态玻璃

效果链严格 vibrancy() → blur(...) → lens(...)，叠加边缘折射、高光与内外阴影；底栏是单一连续玻璃胶囊，液滴可拖拽滑动。玻璃组件全部来自官方 catalog 源码。

01

官方玻璃源码

Kyant0 catalog 的 LiquidBottomTabs / Button / Toggle / Slider 及 DampedDragAnimation 原样引入，唯一玻璃库为 Backdrop 2.0.1。

02

自动识别软件

自动列出已装应用（名称 + 包名），点选后包名自动带入全部软件工具，不用手填；支持搜索、仅第三方 / 全部切换。

03

软件 / 系统分区

工具页分成软件工具与系统工具两大区；系统工具含电量修改、自定义脚本、动画速度缩放等快捷控制。

04

AI 操作手机

OpenAI-compatible / Anthropic / Gemini，读屏 · 点击 · 滑动 · 输入 · 启动 App · shell 工具链；每工具 Off / Ask / Auto，危险动作二次确认。

安装前提

  • 先安装并启动 Shizuku（或 Sui），通过无线调试 / ADB 激活并授权
  • AI 功能需在 App 设置页自行填写 Provider、Base URL 与 API Key
  • 部分能力依赖 ROM：iptables 防火墙需 root，pm hide 等可能被限制
!

关于折射的硬性前提

  • 库源码 isRuntimeShaderSupported() 判定为 SDK_INT >= 33，lens() 不支持时直接返回
  • 因此 Android 13+ 才有边缘折射；Android 12 只有模糊与高光，Android 11 及以下连 RenderEffect 都不可用
  • 这是 Backdrop 库自身限制，原样使用官方组件也无法绕过
